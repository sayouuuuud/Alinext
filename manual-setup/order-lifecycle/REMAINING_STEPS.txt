ALI FLEET — خطوات يدوية متبقية

1) قاعدة البيانات
- راجع ثم شغّل الملف order-lifecycle.sql يدويًا مرة واحدة.
- لم يتم تشغيل أي SQL أو تعديل أي مشروع Supabase بواسطة v0.
- بعد التشغيل يُفضّل مراجعة Supabase Security/Performance Advisors يدويًا.

2) البريد الإلكتروني
- لم تتم إضافة Resend ولم يتم استدعاؤه ولم تُضف أي متغيرات بيئة خاصة به، بناءً على طلبك.
- جدول notification_email_outbox موجود كصف انتظار خامل فقط؛ لا توجد أي عملية ترسل رسائل.
- إذا رغبت بتفعيل البريد مستقبلًا فستحتاج طبقة خادمية تقرأ الصفوف pending وتحدّثها بعد الإرسال مع idempotency key.

3) التحقق بعد تشغيل SQL
- أنشئ طلبًا pending من الواجهة.
- اختبر الاعتماد والتجهيز والشحن والتسليم من لوحة الإدارة.
- اختبر تأكيد الاستلام والإلغاء وإعادة الطلب من حساب مستخدم حقيقي.
- اختبر أن المستخدم لا يستطيع فتح طلب أو فاتورة أو إشعار يخص مستخدمًا آخر.

4) بيانات الاختبار
- لم يتم إنشاء مستخدم أو طلب أو بيانات تجريبية، ولم يتم لمس بيانات Supabase الحالية.
