Add these Vercel project variables before testing external email delivery:
- SMTP_USER: the Gmail address that sends order email.
- SMTP_APP_PASSWORD: a Google App Password for that account (2-Step Verification must be enabled).
- SMTP_FROM_EMAIL: optional From address; defaults to SMTP_USER.
- SMTP_FROM_NAME: optional sender name; defaults to ALI FLEET.
- CRON_SECRET: optional secret for GET/POST /api/internal/email-outbox retries.

No Resend integration or RESEND_* variable is used.
Without SMTP_USER and SMTP_APP_PASSWORD, order updates continue normally and queued email remains pending. After adding both values, create or update an order to test delivery, or call the protected retry endpoint with Authorization: Bearer <CRON_SECRET>.
